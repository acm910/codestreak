# CodeStreak 设计文档中心

> **CodeStreak** —— 把刷题变成不可断的连胜。
> 面向算法竞赛选手与求职面试者的跨平台刷题打卡与赛训一体化应用（HarmonyOS / ArkTS）。

本目录是项目的**单一事实来源**（Single Source of Truth）。产品需求、视觉规范、页面规格、技术设计与项目规范全部在此维护；`docs/产品原型/` 仅作只读参考。

## 5. 文档约定

- **命名**：`NN-中文标题.md`，两位序号、同层连续、不含空格。
- **头部**：每份文档以 YAML front matter 开始，字段 `doc-id / title / category / status / version / updated / related`。
- **结构**：编号二级标题（`## 1.` …），结尾必有"变更记录"表。
- **状态**：`草稿` → `评审中` → `生效`（可据此开发）→ `已归档`；侧态 `待确认`（有 Q-xx 未决）、`规划中`（未进入本期）、`参考`（只读素材）。完整流转见 [文档编写与命名规范](05-项目规范/01-文档编写与命名规范.md) §12。
- **引用**：文档间用相对 Markdown 链接；不得链接到不存在的文件。
- **变更**：合并请求必须同时更新受影响的文档与 06-01 裁决表。详见 [文档编写与命名规范](05-项目规范/01-文档编写与命名规范.md)。
