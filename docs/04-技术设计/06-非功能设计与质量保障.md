# 非功能设计与质量保障

## 1. 目的与度量口径

本文定义 CodeStreak 的**性能预算、可用性与容错、安全、隐私合规、可维护性、可观测性、测试策略、质量门禁、发布灰度与风险登记**。所有指标均给出口径与验证方式，避免"感觉很快"式验收。数据模型见 [数据模型设计](03-数据模型设计.md)，同步链路见 [平台同步与难度归一化](04-平台同步与难度归一化.md)。

- 目标机型基线：HarmonyOS NEXT `compatibleSdkVersion 6.1.1(24)`，8GB 内存、120Hz 屏；所有性能数字在该基线取 **P50**，P90 允许超 20%。
- 测量环境：release 构建（非 debug）、关闭 DevEco 调试器、首次安装与二次冷启动分别统计。

## 2. 性能预算

| 指标 | 预算 | 测量口径 | 验证方式 |
| --- | --- | --- | --- |
| 冷启动 | **≤ 800ms**（P90 ≤ 1.0s） | `onCreate` → 首帧上屏（`loadContent` 回调 + 首帧绘制），中端机 3 次取中位 | DevEco Profiler 启动模板，每版本 5 次取中位 |
| 首屏可交互 | **≤ 1.2s**（有缓存 ≤ 300ms） | 首帧后首个可点击控件响应（今日打卡页，4G 弱网模拟） | 埋点 `cs_first_frame` + 手动秒表校验 |
| 列表滚动 | **60fps**，掉帧率 **< 1%** | 题单矩阵 200 行连续滑动 10s，jank 帧 / 总帧 | Profiler 帧率 + 自定义 jank 计数 |
| 热力图渲染 | **< 16ms** | 112 格（16 周 × 7 天）一次布局+绘制 | 单测基准 + trace `HeatmapRender` |
| 同步吞吐 | 200 条提交 **< 2s** | 适配器返回 JSON → 事务提交完成（不含网络） | 基准用例 `SyncBench.test.ets`（mock 数据） |
| 内存峰值 | **< 180MB** | 前台 PSS 峰值（启动 + 滚动 + 同步三场景取最大） | Profiler memory，连续 3 次 |
| 包体积 | **HAP ≤ 20MB**，安装总包 **≤ 30MB** | release HAP 大小 / 安装后总占用 | 构建产物检查（门禁阻断） |
| 耗电与后台 | 后台零常驻 | 8h 待机耗电 < 2%；无后台轮询、无长时任务 | 功耗测试；`onBackground` 取消所有定时器 |

## 3. 性能实现要点

| 主题 | 要求 | 反例 |
| --- | --- | --- |
| 长列表 | `LazyForEach` + `IDataSource` + 固定 `cachedCount=6`，item 复用；key 用 `problem.id` | 用数组下标当 key，导致整列重建 |
| 布局 | 列表项固定高度、避免嵌套滚动与二次 `measure`；避免 `layoutWeight` 与自适应高度混用 | 卡片内再嵌 `List` |
| 图片与图标 | 头像 96×96 WebP 并本地缓存；功能图标用 `SymbolGlyph` 字体图标，不用 PNG 雪碧图 | 直接加载网络原图 |
| build 内计算 | 难度色、百分比、日期格式化全部在 ViewModel 预计算为 `@Trace` 字段 | `build()` 里 `difficultyColor(x)` 每次重算 |
| 精准刷新 | `@Monitor` 只监听 `localDay`、`acCount`、`targetProgress`、`streakCurrent`；同步事件 200ms 合并节流 | 收到事件就整页 `@State` 重刷 |
| 热力图 | 112 格用 `Grid` 静态渲染（实测 <16ms）；若扩到 53 周（371 格）改用 `Canvas` + `OffscreenCanvasRenderingContext2D` 离屏预绘 | 371 个组件逐个 `animate` |
| 数据库 | 分页查询 + 批量事务；聚合交给 SQL（第 03 号文档第 8 节）；避免逐条 `querySql`（N+1） | 循环里查 `check_in` |
| 网络 | 四平台并发、响应体 > 2MB 截断、gzip、超时 10s | 串行拉取四平台 |
| 启动 | 首帧后再初始化同步/日历/榜单（延迟 300ms）；首装建库与种子数据异步，页面先空态 | 启动时同步建库并阻塞首屏 |

## 4. 可用性与容错

| 场景 | 离线/异常表现 | 兜底 |
| --- | --- | --- |
| 今日打卡 | 可读缓存 AC、可手动补录、可补签；顶部显示"离线，数据待校验" | 本地事务先落库，联网后校验 |
| 题单矩阵 | 可读已缓存题单与完成度；编辑本地生效 | 标记 `pending_sync`，恢复后重试 |
| 比赛日历 | 读最近一次快照并标注"截至 19:42" | 超过 7 天提示刷新 |
| 统计榜单 | 本地聚合全部可用（热力图、难度分布、徽章） | 好友榜显示上次快照 |
| 同步 | 失败不阻断任何本地功能；自动/授权同步失败自动降级模式 C（深链 + 手动打卡） | 1m/5m/15m 退避 + 手动重试 |
| 同步方式可见性 | 平台卡固定显示"自动/授权/手动 + 上次同步时间"（`platform_account.sync_mode` + `last_sync_at`） | 模式 C 也必须显示"手动"，禁止伪装为自动同步 |
| 崩溃 | 关键写操作单事务，异常回滚 | 启动检测 `dirty` 标记并重建聚合 |

- **提示分级**：Toast（部分成功）→ 行内提示（单平台失败）→ 全屏空态（未绑定）→ 对话框（需重新登录）。
- **空态**：未绑定平台、无提交、无比赛、断签四类各有一句可执行引导（"绑定 LeetCode"、"去题库挑 2 题"），不留白屏。
- **重试**：网络类自动退避，鉴权类只给"重新绑定"按钮；重试按钮 60s 内防连点。

## 5. 安全

| 权限 | 用途 | 说明 |
| --- | --- | --- |
| `ohos.permission.INTERNET` | 拉取平台数据 | 唯一网络权限 |
| `ohos.permission.GET_NETWORK_INFO` | 判断在线状态 | 离线队列依赖 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | 21:30 打卡提醒 | `reminderAgentManager` 必需 |

不申请位置、通讯录、麦克风、相册、后台常驻；数据导出走 `filePicker` 由用户逐次授权，不申请存储权限。

- **凭据**：HUKS 生成不可导出 AES-256-GCM 密钥（别名 `cs_cred_<platform>`），密文（iv + tag + cipher）存 Preferences；RDB 仅存 `cred_ref` 与指纹；解绑即删密钥与密文；日志、导出、云备份一律排除。
- **Web 组件**：仅用于 LeetCode/洛谷登录。域名白名单 `leetcode.cn`、`www.luogu.com.cn`；`onLoadIntercept` 拦截非白名单跳转与 `http:`；禁用 `file://`、`resource://` 与外部 Intent；登录完成立即销毁 Web 组件并清理 Cookie/WebStorage；禁止把 URL 参数直接拼进 `src`（防任意 URL 注入）。
- **日志脱敏**：Cookie、token、请求头、响应体禁止打印；标识类字段用 `%{private}s`；错误上报只带 `error_code` 与调用链，不带报文。
- **数据导出**：v1 仅 `.ics` 日历导出（赛事标题、开始/结束时间、URL），由用户主动触发；JSON/Markdown 刷题日志导出为 v1.1 占位，点击提示"v1.1 开放"，不静默失败。任何导出都不含 `cred_*`、`extra`、好友昵称与头像。
- **云备份范围**：`user`、`platform_account`（剔除 `cred_ref`/`cred_fingerprint`）、`problem`、`check_in`、`streak_record`、`problem_set(_item)`、`contest(_registration)`、`upsolve_*`、`badge`、`user_badge`、`leaderboard_entry`、`app_setting`；**不含** `submission` 原始行与任何凭据，恢复后重新同步。

## 6. 隐私合规

| 个人信息 | 字段 | 目的 | 存储 | 保留 | 可删除 |
| --- | --- | --- | --- | --- | --- |
| 账号标识 | `handle`、`uid_public`、`nickname`、`avatar_ref` | 展示与归属 | RDB | 至解绑/删除 | 是 |
| 平台凭据 | Cookie / token | 同步本人数据 | HUKS + Preferences 密文 | 至解绑 | 是 |
| 做题记录 | `submission`、`check_in`、`upsolve_*` | 打卡与统计 | RDB | 原始 180 天，聚合永久 | 是 |
| 设置偏好 | `app_setting`、Preferences | 功能配置 | 本地 | 至删除 | 是 |

- **告知同意**：首启展示隐私政策与用户协议，**未同意不初始化网络与数据库**；设置页可撤回同意，撤回后停止同步并清空凭据。
- **账号与数据删除**：设置 → "清空全部数据"，二次确认后清空 17 表、Preferences、HUKS 密钥，并删除本地导出文件索引；操作不可撤销，需输入确认词。
- **第三方传输说明**：仅在用户主动触发同步时向其绑定的平台发起 HTTPS 请求，传输内容为凭据与查询参数，不含本地统计；v1.0 **无自有后端**，不向任何第三方回传数据。

## 7. 可维护性

| 层 | 目录 | 允许依赖 | 禁止 |
| --- | --- | --- | --- |
| Presentation | `pages/`、`components/` | Application、Domain 常量 | 直接 `relationalStore`、直接 `http` |
| Application | `viewmodel/`、`services/` | Domain、Data、Platform | 写 DDL、拼 SQL 字符串 |
| Domain | `domain/` | 仅标准库 | 依赖 `@kit.*`（保证可纯单测） |
| Data | `data/` | Platform、Domain | 依赖 UI 类型 |
| Platform | `platform/` | `@kit.*` | 业务规则 |

| 日志域 | 模块 | 级别约束 |
| --- | --- | --- |
| `0x0C01` | Data/RDB | info 记录建库/迁移；error 记录事务失败与 `SQLITE_*` |
| `0x0C02` | Sync | info 记录 job 摘要；warn 耗时 >8s；error 记录错误码 |
| `0x0C03` | UI | 仅 warn/error，禁止逐帧日志 |
| `0x0C04` | Security | 只记事件类型，永不记凭据 |
| `0x0C05` | Perf | 仅基准与启动打点，release 可关闭 |

| 错误码 | 含义 | 用户可见文案 |
| --- | --- | --- |
| `ER-1001` | 网络超时 | 网络较慢，已保存本地记录 |
| `ER-1002` | 无网络 | 当前离线，联网后自动同步 |
| `ER-1003` | 被限流 | 请求过于频繁，稍后自动重试 |
| `ER-2001` | 登录态过期 | 登录已失效，请重新绑定 |
| `ER-2002` | 凭据无效 | 凭据无效，请重新绑定 |
| `ER-2003` | 平台风控 | 平台限制访问，请稍后再试 |
| `ER-3001` | 返回结构变更 | 平台接口变更，已降级处理 |
| `ER-3002` | 难度无法识别 | 已按默认 ★3 处理 |
| `ER-4001` | 数据库打开失败 | 数据加载失败，请重启应用 |
| `ER-4002` | 事务冲突 | 保存失败，请重试 |
| `ER-4003` | 迁移失败 | 数据升级失败，可恢复云备份 |
| `ER-5001` | 通知权限被拒 | 未开启通知，提醒无法送达 |
| `ER-5002` | 提醒注册失败 | 提醒创建失败，请检查系统设置 |
| `ER-6001` | `.ics` 导出失败 | 导出失败，请更换保存位置 |
| `ER-6002` | 备份失败 | 备份失败，不影响本地数据 |
| `ER-6003` | 功能未开放（JSON/Markdown 导出） | 该功能将在 v1.1 开放 |
| `ER-7001` | 未知平台/不支持 | 暂不支持该平台 |

**Feature Flag**（存 `app_setting`，默认值即代码默认，远程不可用时不阻塞）：`ff_sync_luogu=true`（洛谷同步开关）、`ff_sync_leetcode=true`、`ff_upsolve_auto=true`（赛后自动建补题任务）、`ff_heatmap_canvas=false`（>16 周时切 Canvas）、`ff_leaderboard_remote=false`（好友榜远端源）、`ff_manual_entry=true`（手动补录）。开关变更须留痕（`app_setting.updated_at` + 埋点 `cs_settings_change`）。

## 9. 测试策略

| 层次 | 范围 | 工具 / 位置 | 门槛 |
| --- | --- | --- | --- |
| 单元测试 | 难度归一化、连续天数、补签、去重、完成度、字节/日期工具 | `@ohos/hypium`，`entry/src/test` | 领域层行覆盖 **≥80%**，用例 ≥120 |
| 契约测试 | 四适配器字段映射与错误码 | 录制 JSON fixture 回放，不连真网 | 每平台 ≥6 用例（正常/空/字段缺失/限流/鉴权失效/结构变更） |
| 集成测试 | RDB 建库、迁移 v1→v2、聚合口径 | `entry/src/ohosTest` | 17 表 CRUD + 6 条聚合 SQL 断言 |
| UI 测试 | 打卡闭环、断网降级、补签、Tab 切换 | `ohosTest` + UiTest | 主流程 100% 通过 |
| 性能基准 | 启动、滚动、热力图、同步 200 条 | 基准用例 + Profiler | 达第 2 节预算 |
| 兼容性 | 直板/折叠/平板（`deviceTypes` 目前为 phone） | 真机矩阵 | 分辨率 1080×2340、1260×2700、折叠展开 2224×2496，深色模式 |

**回归清单（每次发版必跑）**：① 绑定/解绑四平台；② 跨天与改时区；③ 双口径校验：3 AC 时 `daily_target_progress=2`、`daily_ac_count=3`、热力图档位 2，补题只进 `daily_ac_count`；④ 补签卡里程碑发放（D7/D30）与余额 2→1→0、断签超窗；⑤ 离线打卡后联网校验；⑥ 升级安装迁移与云备份恢复；⑦ `.ics` 导出与"清空全部数据"；⑧ 提醒注册与关闭；⑨ 模式 C 手动打卡与"手动"徽标、上次同步时间展示。

## 10. 质量门禁

| 门禁 | 阈值 | 执行 |
| --- | --- | --- |
| 静态扫描 | `code-linter` 0 error；`@security/*` 规则 0 error | CI 阻断合并 |
| 单测覆盖 | 领域 ≥80%，整体 ≥60% | CI 报告 |
| 构建体积 | HAP ≤ 20MB、总包 ≤ 30MB | 构建后脚本检查，超限阻断 |
| 崩溃率 | crash-free ≥ **99.5%**（灰度 7 天） | 崩溃采集看板 |
| 启动 | 冷启动 P90 ≤ 1.0s | 基准用例 |
| 主流程 | UI 主流程全绿 | `ohosTest` |

## 11. 发布与灰度

分阶段放量 **5% → 20% → 50% → 100%**，每阶段观察 24h；灰度期开启全部 Feature Flag 的"保守档"（`ff_leaderboard_remote=false`）。

**回滚条件**（任一命中即回滚）：crash-free < 99%、同步失败率 > 20%、冷启动 P90 > 1.5s、HAP 体积 > 20MB、出现数据丢失或迁移失败反馈 ≥3 例。回滚手段：应用市场分阶段撤回 + 远程关闭对应 Feature Flag；回滚不删本地数据，迁移失败场景走"恢复云备份"引导。

## 12. 风险登记册

| 风险 | 概率 | 影响 | 缓解 | 负责人角色 |
| --- | --- | --- | --- | --- |
| LeetCode GraphQL / 洛谷 JSON 结构变更 | 高 | 同步中断 | 契约测试 + `PARSE_ERROR` 降级 + 手动补录兜底 | 数据架构师 |
| 平台风控封禁高频请求 | 中 | 单平台不可用 | 严格限速、UA 标识、失败即停、禁止绕过 | 后端/集成工程师 |
| AtCoder 难度尺度与 CF 不等价导致分布失真 | 中 | 统计口径偏差 | 标注"待验证"，v1.1 用分位对齐校准 | 算法工程师 |
| 后台限制导致同步不及时 | 高 | 打卡延迟 | 前台恢复同步 + 21:30 提醒 + 手动刷新 | 客户端工程师 |
| 模式 C 手动数据被误认为自动同步 | 中 | 信任与合规风险 | UI 强制显示同步方式 + 上次同步时间；埋点校验 `sync_mode` 与 `last_sync_at` 一致性 | 产品经理 |
| 补签规则被滥用（争议） | 低 | 公平性 | 7 天窗口、连续 ≤2 天、余额上限、操作留痕 | 产品经理 |
