## 6. 与设计的偏差登记

| 编号 | 偏差 | 原因 | 影响 | 后续 |
| --- | --- | --- | --- | --- |
| DEV-01 | 组件按 4 个文件聚合（Common/Cards/Visuals），未按 C-xx 一文件一组件 | 首版提速，21 个组件内聚管理 | 单文件较大（Cards ≈ 870 行），不利并行开发 | M3 前按 C 编号拆分 |
| DEV-02 | 图标使用字符占位（✓ ★ 🔥 →） | 未引入图标字体，避免首版资源依赖 | 视觉与设计稿有差距 | 换 `SymbolGlyph` 或字体图标 |
| DEV-03 | RDB 仅落 5/17 张表 | 先保证打卡与题目可用 | 题单/徽章/榜单未持久化 | 接同步时按 DbSchema 机制追加 |
| DEV-04 | 未接四平台同步 | 网络与合规需专项（04-07 Spike） | 数据来自种子库，非真实 | M1 剩余工作 |
| DEV-05 | 未接 `reminderAgentManager` | 权限与真机验证成本 | 21:30 提醒为界面开关 | M2/M3 |
| DEV-06 | `daily_ac_count` 固定为种子值 3，未按 submission 聚合 | 无 sync 与 submission 表数据 | 热力图与摘要为静态示例 | 接同步后改为聚合查询 |
| DEV-07 | 庆祝弹层用 Stack 遮罩实现，未用 `bindContentCover` | 降低 API 兼容风险 | 转场动画较简单 | 视觉打磨时替换 |
| DEV-08 | 深色主题通过 `setColorMode(DARK)` 与页面底色实现，未做系统级主题资源 | v1.0 单主题 | 无影响 | 保持 |

## 7. 已知缺口与下一步

1. **平台同步**：CF 的 `user.status` / `user.info` 响应映射已完成并用契约测试覆盖；下一步接 `@kit.NetworkKit` HTTP 调用、`submission` 落库与增量水位，再扩展其余三平台；
2. **数据补全**：submission / problem_set / badge 等表与聚合查询，`daily_ac_count` 改为真实聚合；
3. **通知**：`reminderAgentManager` 每日 21:30 与赛前 15 分钟，权限拒绝路径；
4. **真机回归**：按 [测试用例集](../07-测试与质量/02-测试用例集.md) 的 P0 逐条执行，重点验证热力图横向滚动、倒计时 HUD 按钮宽度、庆祝弹层遮罩层级；
5. **签名与上架**：配置自动签名，产出可安装包。
