| DEV-04 | 仅接 Codeforces 与 AtCoder，洛谷/LC 未接 | 逐平台验证：CF 官方 API、AtCoder 第三方 API 均已跑通 | 洛谷/LC 数据仍来自种子 | M1 剩余工作 |

| DEV-07 | 庆祝弹层用 Stack 遮罩实现，未用 `bindContentCover` | 降低 API 兼容风险 | 转场动画较简单 | 视觉打磨时替换 |

## 7. 已知缺口与下一步

1. **平台同步**：四平台代码全部完成（CF 已真机验证，AtCoder/洛谷/LC 待验证）；LC 需补内置 WebView 登录态，洛谷需补授权页；
2. **授权体验**：Cookie 迁入 Asset Store，补逐平台独立开关（DEV-13/15）；
3. **数据缺口**：好友榜、题单订阅进度、赛后补题按「无数据即空态」处理（DEV-17）；接入后端/赛果源后填充；
4. **平台赛事**：已接 CPC Finder（ICPC/CCPC）、Codeforces、AtCoder；LC/洛谷赛程需登录态，暂为空态（DEV-19）；
5. **重试**：已支持启动时消费单槽位重试；下一步改为 `workScheduler` 定时驱动并支持多平台并发；
6. **通知**：每日 21:30 已接 `reminderAgentManager`，待真机验证送达与权限拒绝路径；赛前 15 分钟提醒未做；
7. **真机回归**：按 [测试用例集](../07-测试与质量/02-测试用例集.md) 的 P0 逐条执行，重点验证空态、LC 登录态、洛谷 403 降级、提醒送达；
8. **签名与上架**：配置自动签名，产出可安装包（缺证书，不作为本轮完成条件）。
