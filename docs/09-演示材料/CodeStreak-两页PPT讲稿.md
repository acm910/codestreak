# CodeStreak 两页 PPT 讲稿

各位老师好，我是余翔宇。我介绍的是 CodeStreak，一个在 HarmonyOS 上把五个刷题平台收在一起的打卡应用。

我们刷题通常散在 Codeforces、AtCoder、洛谷、牛客、LeetCode，今天做了几题、连续几天、下一场比赛，都要来回切网站。CodeStreak 把今日打卡、题单矩阵、比赛日历、统计榜单放在一个应用里：每天完成两道题，连续天数加一；题单分求职和竞赛两条赛道；赛程按时间排好，点一下就能去报名或看榜单。

第二页想说明它不只是界面。今日 AC、连续天数、热力图、难度分布都从本地记录算出来，没有数据就显示空态，不拿演示数字充数；五个平台都能同步，失败会按 1、5、15 分钟退避重试；工程上有 90 条单测、87.7% 行覆盖，代码已经开源。

左边这段动图是真实操作：打卡、切赛道、筛选平台、打开赛程。一句话总结，CodeStreak 让“每天做两题”这件事看得见、接得上、断不了。谢谢大家。
