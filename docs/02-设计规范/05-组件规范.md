# 组件规范

本文是 CodeStreak 40 个 UI 组件的唯一规格来源。尺寸以 vp 计（原型 1px ≈ 1vp，1rem = 16px），颜色只引用 [设计令牌规范](02-设计令牌规范.md) 的语义令牌（写作 `cs.color.*`），组件内禁止裸 HEX；间距基线见 [布局栅格与间距规范](04-布局栅格与间距规范.md)，弹层与全局状态见 [弹层与全局状态](../03-页面设计/06-弹层与全局状态.md)。

## 2. 通用规则

### 2.1 尺寸基准与形状

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 基准宽度与内边距 | 宽 360vp、内容可用宽 328vp；大卡 16vp / 行卡 12vp / 徽标 2–8vp | 手机竖屏、左右边距 16vp；与 4vp 基数对齐，同类组件同屏必须一致 |
| 圆角 | 2 / 4 / 6 / 8 / 12vp / full（阶梯以 [布局栅格与间距规范](04-布局栅格与间距规范.md) 第 6 节为准） | 2 热力块；4 徽标与 Chip；6 32vp 及以下图标底、周矩阵格；8 按钮、输入、Toast；12 卡片、抽屉、弹窗、AppBar Logo 底；full 胶囊、圆环、头像。内层圆角 = 外层 − 内边距，最小 4vp |
| 描边与阴影 | 默认无描边 | 仅 L1 货架用 `border.subtle` 1vp；焦点态 `primary.container` 1vp + 外扩 2vp。阴影仅 3 处：AppBar 底 `0 1vp 8vp rgba(0,0,0,.25)`、TabBar 顶 `0 -1vp 12vp rgba(0,0,0,.35)`、弹层 |
| 最小热区 | 44×44vp | 视觉可 28/32vp，用 `.responseRegion()` 补足，相邻热区间隔 ≥8vp |

### 2.2 六态定义

| 状态 | 判定 | 视觉 | 约束 |
| --- | --- | --- | --- |
| 默认 | 无交互 | 按各组件规格 | — |
| 按压 | 手指按下 | 次按钮 `surface.bright`；主按钮 `translateY(1vp)` + 亮度 95%；卡片 scale 0.98 | ≤120ms，松手立即回弹 |
| 选中 | 多选一 / 开关 | `primary.container` 底 + `primary.on-container` 文本 | 必须同时有图标或文案，不得仅靠颜色 |
| 禁用 | 前置条件不满足 | 底 38% 不透明 + `text.ghost` 文本 | 保留图标与文案，不得整块消失 |
| 加载 | 请求进行中 | 按钮内 18vp 环形；容器用 C-40 骨架 | 除首次启动外禁止整屏遮罩 |
| 空 | 数据 0 条 | 切换 C-39 空态 | 空态必须给出下一步操作 |

### 2.3 图标、文本与命名

| 项 | 约定 |
| --- | --- |
| 图标尺寸 | 14 徽标内联 / 16 按钮与行内箭头 / 18 强调按钮与开关 / 20 AppBar 与区块头 / 22 TabBar / 24 卡片主图标 |
| 文本与数字 | 标题 `maxLines(1)` + `TextOverflow.Ellipsis`；描述 `maxLines(2)`；元信息 1 行；平台名、题号、难度、状态词不得进入截断容器。连续天数、倒计时、完成率、排名统一 `.fontFeature('"tnum" 1')` |
| 类名与 Props | `Cs` + PascalCase（`CsTargetCard`）／`<组件名>Props`；`variant` 表语义变体（如 `'solid' \| 'tint'`），`size: 'sm' \| 'md' \| 'lg'`；事件统一 `on` + 动作（`onCheckIn`） |
| 状态归属 | `state` 由父级派生；组件内不持有业务状态、不直接请求接口 |
| 无障碍 | 可点组件必须 `.accessibilityText()`；纯图标按钮语义等同其 `aria-label`（如"同步平台数据"） |
| 颜色 | 只允许 `$r('app.color.cs_color_*')` 或 `CsColor.*`；半透明用 `withAlpha()`，禁止手写 `#33` 前缀 |

```ts
Row({ space: 2 }) {
  ForEach(this.weeks, (week: number[]) => {
    Column({ space: 2 }) {
      ForEach(week, (lv: number) => {
        Row().width(10).height(10).borderRadius(2)
          .backgroundColor(this.heatColor(lv))
          .shadow(this.shadowOf(lv))    // 第 5 档返回 secondary.fixed 光晕，其余返回空
          .onClick(() => this.showDayTip(lv))
      })
    }
  })
}.scrollable(ScrollDirection.Horizontal).scrollBar(BarState.Off)
```

## 9. 组件验收清单

- [ ] 40 个组件均有唯一编号，与第 1 节总览表逐项对应，无未编号组件。
- [ ] 全量组件无裸 HEX，颜色全部来自 `cs.color.*` 令牌或 `withAlpha()`。
- [ ] 所有可点元素热区 ≥44×44vp；纯图标按钮均具备 `accessibilityText`。
- [ ] 主按钮底色恒为 `primary.container`、文案恒为 `primary.on-container`，同屏不超过 1 个 44vp 主按钮。
- [ ] C-06 完成后右按钮为 `secondary.container` 底"已打卡 AC"且 `enabled(false)`；C-07 行为一致。
- [ ] C-05 为 7 列 28×28vp、圆角 6vp；C-32 为 10×10vp、圆角 2vp、间距 2vp、7 行、五档取令牌第 8.1 节。
- [ ] C-14 底色为难度色 @20%、文本为难度色，0.5 星取较低档；C-13 solid 与 tint 未在同一层级混用。
- [ ] C-26 秒格数字为 `secondary`，其余三格为 `primary.container`，四格数字均启用 tabular-nums。
- [ ] C-29 左侧 2vp 竖条仅在"报名中/备赛中"出现，且同时存在状态文字。
- [ ] 六态（默认/按压/选中/禁用/加载/空）在同一组件内视觉可区分，禁用态保留图标与文案。
- [ ] 数字类组件（C-04/C-26/C-27/C-33/C-35）宽度稳定，无因数值变化引起的抖动。
- [ ] 深色背景下正文对比度 ≥4.5:1，`text.ghost` 未承载任何可读信息。
