# 交互与动效规范

## 1. 目的与范围

本文定义 CodeStreak 的动效原则、时长与曲线令牌、交互态、关键动效清单、触觉反馈、手势、滚动与吸顶、声音策略、降低动效与性能红线。

- **负责**：动效何时发生、持续多久、用什么曲线、交互态视觉、手势约定、性能预算。
- **不负责**：颜色见[设计令牌规范](02-设计令牌规范.md)；间距与热区见[布局栅格与间距规范](04-布局栅格与间距规范.md)；文案见[设计原则与视觉风格](01-设计原则与视觉风格.md) §7；组件结构见[组件规范](05-组件规范.md)。
- **落地载体**：ArkTS `animateTo` + `@ohos.curves`，统一封装为 `CsMotion`（§3.3），业务代码不得内联时长常量。
- **权威边界**：动效时长、曲线、交互态以本文为准；[组件规范](05-组件规范.md)中各组件标注的"按压 120ms""填充 300ms""弹入 300ms"等数值属并行编写遗留，按本文令牌归一（卡内按压 90ms、进度填充 500ms、庆祝弹入 320ms），组件规范中的对应描述需随之修订。

## 2. 动效原则

| 原则 | 规定 | 反例 |
| --- | --- | --- |
| **机械精确**（Mechanical） | 动效只表达"状态 A → 状态 B"，不做弹性炫技；位移距离 ≤ 8vp，缩放幅度 ≤ 4%；同一元素只用一种变换（位移 **或** 缩放，不同时用） | 打卡按钮回弹三次、卡片带旋转入场 |
| **快于观赏**（Faster than spectacle） | 所有功能性动效 ≤ 320ms；超过 200ms 的动效必须能被跳过或自动结束；用户连续操作时后一次动画直接覆盖前一次 | 1s 的页面转场、2s 的庆祝粒子 |
| **只动必要元素**（Only what changes） | 一次状态变更只让"确实变化的元素"动；布局中其他元素不得跟着动 | 点一个按钮导致整张卡片缩放、列表全部重排 |

补充裁决：**能用 0ms 解决的不做动画**。Tab 高亮、筛选选中、状态徽记替换属于"状态翻转"，一律 `motion.instant`（0ms），不做渐变、不做滑块位移。

## 3. 时长与曲线令牌

### 3.1 时长

| 令牌 | 时长 | 曲线 | 适用场景 |
| --- | --- | --- | --- |
| `motion.instant` | 0ms | — | Tab 高亮、筛选选中、已打卡徽记替换、状态文案切换 |
| `motion.press` | 90ms | `ease-press` | 按压位移/缩放的回弹 |
| `motion.enter` | 180ms | `ease-standard` | 元素出现、Toast 进场、错误提示浮现 |
| `motion.exit` | 120ms | `ease-exit` | 元素消失、Toast 退场、弹层关闭 |
| `motion.sheet` | 240ms | `ease-standard` | 底部抽屉（C-17）上滑/下滑 |
| `motion.celebrate` | 320ms | `ease-overshoot` | 打卡成功弹窗（C-16）弹入与图标 bounce |
| `motion.progress` | 500ms | `ease-standard` | 进度条（C-15）填充、环形进度 |
| `motion.toast-dwell` | 2500ms | — | Toast 停留时长（不含进出场） |
| `motion.skeleton` | 1200ms（循环） | `linear` | 骨架屏（C-40）呼吸，仅加载中使用 |

### 3.2 曲线

| 令牌 | cubic-bezier | 特征 | 用途 |
| --- | --- | --- | --- |
| `ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 快起步、慢收尾，最有"机械感" | 出现、抽屉、进度、热力格点亮 |
| `ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 慢起步、快离场，不拖泥带水 | 一切消失/关闭 |
| `ease-press` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 近似线性，去掉回弹 | 按压 |
| `ease-overshoot` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 约 5% 过冲，仅庆祝使用 | C-16 弹入、图标 bounce |
| `linear` | `linear` | 恒速 | 仅骨架屏循环 |

禁止使用 `Curve.Spring`、`Curve.Bounce`、`Curve.Elastic` 作为通用曲线：弹性属于"娱乐化"语义，只允许在 C-16 内部以 `ease-overshoot` 表现一次。

### 3.3 ArkUI 落地

```ts
import { curves } from '@kit.ArkUI';

export class CsMotion {
  static readonly PRESS_MS: number = 90;
  static readonly ENTER_MS: number = 180;
  static readonly EXIT_MS: number = 120;
  static readonly SHEET_MS: number = 240;
  static readonly CELEBRATE_MS: number = 320;
  static readonly PROGRESS_MS: number = 500;
  static readonly TOAST_DWELL_MS: number = 2500;

  static readonly EASE_STANDARD: curves.ICurve = curves.cubicBezierCurve(0.2, 0, 0, 1);
  static readonly EASE_EXIT: curves.ICurve = curves.cubicBezierCurve(0.4, 0, 1, 1);
  static readonly EASE_PRESS: curves.ICurve = curves.cubicBezierCurve(0.3, 0, 0.8, 0.15);
  static readonly EASE_OVERSHOOT: curves.ICurve = curves.cubicBezierCurve(0.34, 1.56, 0.64, 1);

  /** 唯一动效入口：统一处理"减弱动效"开关（§10） */
  static play(duration: number, curve: curves.ICurve, action: () => void): void {
    const reduced: boolean = AppStorage.get<boolean>('reduceMotion') ?? false;
    animateTo({ duration: reduced ? 0 : duration, curve }, action);
  }
}
```

```ts
// 按压态：stateStyles 即时生效，位移用 animation 平滑 90ms
@Styles function pressedStyle(): void {
  .opacity(0.92)
  .translate({ y: 1 })
}

Button('完成打卡')
  .stateStyles({ pressed: this.pressedStyle })
  .animation({ duration: CsMotion.PRESS_MS, curve: CsMotion.EASE_PRESS })
```

## 4. 交互态规范

| 状态 | 视觉表现 | 时长 | 约束 |
| --- | --- | --- | --- |
| 默认 | 令牌原样（见 02-02 §7） | — | — |
| 按压 | 按钮 `translateY(1vp)` **或** `scale(0.98)`；卡片 `scale(0.98)`；列表行背景 → `cs.color.surface.bright` | 90ms | 同一元素只能用一种变换；禁用态不响应 |
| 选中 | 背景 → `cs.color.primary.container` + 文案 `primary.on-container`；或文案 `primary.container` + 左侧 2vp 竖条 | **0ms** | 即时切换，无滑条、无渐变 |
| 禁用 | `opacity(0.4)`，形状与尺寸不变 | 0ms | 不加删除线、不改圆角、不用 `text.ghost` 之外的降级色 |
| 加载中 | 按钮内 16vp 转圈且保留原文案；列表用 C-40 骨架 | — | 禁止全屏 loading 遮罩 > 300ms；加载中禁止重复点击 |
| 焦点 | 1vp `cs.color.primary.container` 描边 + 外扩 2vp | 0ms | 与 02-02 §9 规则 4 一致，不用颜色闪烁 |
| 错误 | 1vp `cs.color.error` 描边 + 下方 12fp 说明 | 0ms | **禁止 shake 抖动动画** |
| 成功 | 1vp `cs.color.secondary` 描边 + 图标替换 | 180ms | 只变描边与图标，不整卡换色 |

## 5. 关键动效清单

| 编号 | 场景 | 元素 | 属性变化 | 时长 / 曲线 | 说明 |
| --- | --- | --- | --- | --- | --- |
| M-01 | 打卡成功 | C-16 弹窗 | `opacity 0→1` + `scale 0.95→1` | 320ms / overshoot | 遮罩同步 180ms 淡入；完整触发流程见[今日打卡页](../03-页面设计/02-今日打卡页.md) |
| M-02 | 打卡成功 | C-16 内图标 | `scale 0.6→1.05→1`（bounce 一次） | 320ms / overshoot，延迟 80ms | 只播一次，不循环 |
| M-03 | Tab 切换 | C-02 项 | 图标与文案颜色即时切换 | **0ms** | 无滑条、无指示器位移、无页面横滑 |
| M-04 | Toast | C-18 | 进场 `translateY(8→0)` + 淡入；退场反向 | 180 / 120ms，停留 2500ms | 同时只显示 1 条，新条替换旧条并重置计时 |
| M-05 | 底部抽屉 | C-17 | `translateY(100%→0)` + 遮罩淡入 | 240ms / standard | 下滑关闭阈值 96vp 或速度 > 800vp/s |
| M-06 | 倒计时刷新 | C-26 四格 | **仅替换字形**，无淡入、无缩放、无位移 | 0ms，每秒一次 | 数字槽等宽（03 §5.4），刷新不得产生抖动 |
| M-07 | 进度条 | C-15 | `scaleX 0→目标值`，锚点左侧 | 500ms / standard | **必须用 `scaleX`**，禁止动画 `width` |
| M-08 | 热力格点亮 | C-32 单元 | 背景色 → 对应档位，`opacity 0.6→1` | 180ms / standard | 只对本次新增格播放；同批最多 20 格，逐格延迟 ≤ 12ms |
| M-09 | 列表项按压 | 列表行 | `scale(0.98)` 或背景提亮（二选一） | 90ms / press | 整行同时变化，内部图标不单独动 |
| M-10 | 下拉刷新 | 页面顶部 | 指示器旋转 + 内容回弹 | 系统 `Refresh` 默认 + 240ms 回弹 | 触发阈值 64vp；仅一级列表页启用 |
| M-11 | 分段切换 | C-19 分段控件 / C-12 筛选胶囊 | 选中背景即时切换 | **0ms** | 不位移滑块（原型已有该反例，需去掉） |
| M-12 | 骨架屏 | C-40 | `opacity 0.4↔0.8` 呼吸 | 1200ms 循环 | 仅首次加载 > 300ms 时出现，数据到达即替换 |

## 6. 触觉反馈

| 场景 | 强度 | 时机 | 备注 |
| --- | --- | --- | --- |
| 打卡成功（C-16 出现） | 中 | 与 M-01 同时 | 全 App 最重要的一次触觉，不可省略 |
| 危险操作确认（取消打卡/删除题单） | 重 | 二次确认弹窗出现时 | 与红色描边同时 |
| 长按进入多选/日期明细 | 轻 | 500ms 长按判定成功瞬间 | 一次，不随手指移动重复 |
| 下拉刷新到位 | 轻 | 越过 64vp 阈值的瞬间 | 只触发一次 |
| 开关切换（C-36） | 轻 | 状态落定后 | — |

```ts
import { vibrator } from '@kit.SensorServiceKit';

export function haptic(effectId: string): void {
  try {
    vibrator.startVibration({ type: 'preset', effectId }, { id: 0, usage: 'touch' });
  } catch (e) {
    // 触觉失败静默：不阻断主流程、不提示用户
  }
}
```

- 需在 `module.json5` 声明 `ohos.permission.VIBRATE`；`effectId` 必须以设备实际支持的 preset 列表为准（用 `vibrator.getEffectInfoSync()` 校验），不支持则静默跳过。
- **明确禁止触觉**：Tab 切换、列表滚动、列表项普通按压、倒计时每秒刷新、Toast 出现、每次点击按钮。
- 频率上限：同一次操作链最多 1 次；1 秒内不得连续 2 次。

## 7. 手势规范

| 手势 | 作用域 | 行为 | 约束 |
| --- | --- | --- | --- |
| 纵向滚动 | 页面主体 | 单指滚动 | 内层横向列表不拦截纵向手势（`nestedScroll` 交由父级处理） |
| 横向滚动 | C-32 热力图、题单横向卡、日历条 | 惯性滚动 + snap（`scrollSnapAlign(ScrollSnapAlign.START)`） | 首屏露出下一张卡 16vp 作为可滑提示 |
| 长按 | 列表行、热力格 | 500ms 触发快捷菜单或日期明细（C-17） | 长按期间不缩放，触发后震动一次 |
| 右滑返回 | 屏幕左/右边缘 | 交系统返回手势处理 | 自定义页面**不得拦截**；Tab 根页面不响应右滑 |
| 下拉 | 页面顶部 | 刷新 | 仅一级列表页启用，详情页与弹窗内禁用 |
| 双击 | — | **全面禁止** | 双击点赞、双击缩放、双击收藏一律不做，误触代价高于收益 |
| 摇一摇 | — | 禁止 | — |
| 多指手势 | — | 禁止自定义双指/三指手势 | 仅保留系统级无障碍手势 |

## 8. 滚动与吸顶

| 规则 | 规定 |
| --- | --- |
| AppBar 行为 | 常驻固定，不随滚动隐藏/变透明（"仪表盘常驻"是风格的一部分） |
| 吸顶实现 | `List` + `ListItemGroup({ header })` + `.sticky(StickyStyle.Header)` |
| 吸顶高度与样式 | 44vp，背景 `cs.color.surface@92%` + 底部 1vp `cs.color.border.subtle` |
| 吸顶偏移 | 滚动容器不含 AppBar 时为 0；若通栏滚动（`Stack`），List 顶部偏移与吸顶偏移必须同时设为 64vp，否则吸顶标题会被 AppBar 压住 |
| 滚动位置保持 | Tab 切换后恢复各页滚动位置（记录 `scrollToIndex` / 偏移），不回到顶部 |
| 滚动条 | 一律隐藏（`BarState.Off`），不使用滚动指示器（`scrollBarWidth` 保留默认以防无障碍场景需要） |
| 惯性 | 使用系统默认惯性；`edgeEffect(EdgeEffect.Spring)` 仅用于纵向列表 |
| 嵌套滚动 | 横向容器内不嵌套纵向列表；热点区域（热力图）外层只允许一个方向可滚 |

## 9. 声音策略

| 项 | 规定 |
| --- | --- |
| 默认状态 | **全部关闭**（静音是默认值，不是可选项） |
| 唯一允许的声音 | 打卡成功音效：≤ 300ms，跟随系统媒体音量，随静音/勿扰模式静默 |
| 开关位置 | C-36 设置页"打卡音效"，默认关；切换后立即生效并持久化 |
| 禁止 | 背景音乐、按键音、滚动音、错误蜂鸣、倒计时滴答 |
| 失败降级 | 音频资源缺失/被系统打断时不报错、不重试、不影响主流程 |

## 10. 降低动效（无障碍）

| 项 | 规定 |
| --- | --- |
| 入口 | C-36 设置页"减弱动效"开关，默认**跟随系统**；用户显式设置后以其为准并持久化（`PersistentStorage`） |
| 开启后的时长 | 全部动效时长 → 0ms；确需过渡时上限 60ms |
| 开启后的行为 | 移除位移、缩放、bounce、骨架呼吸；仅保留 `opacity` ≤ 120ms 或直接切换 |
| 庆祝弹窗 | 改为静态出现，3.5s 后自动关闭（保留可点击关闭） |
| Toast | 停留延长至 3500ms（失去进场提示后需要更长阅读时间） |
| 进度条 | 直接跳到目标值，不做 500ms 填充 |
| 实现 | 所有动效必须走 `CsMotion.play()`（§3.3），禁止业务代码直接调 `animateTo`，否则开关会被绕过 |

> 工程说明：HarmonyOS 系统级"移除动画"开关目前没有稳定的公开查询 API。v1.0 以应用内开关为唯一可靠判据，并在 `Configuration` 变化时重读；后续 SDK 若提供动效缩放字段，优先接入并置为默认来源。

## 11. 动效反例与性能红线

### 11.1 反例

| 反例 | 问题 | 正确做法 |
| --- | --- | --- |
| 动画 `width` / `height` / `padding` / `margin` / `top` / `left` | 每帧触发布局重算，必掉帧 | 只用 `transform`（`scale` / `translate`）与 `opacity` |
| 列表逐项入场动画 | N 个并发动画，首屏卡顿且越过停留时间 | 整页只做一次淡入，或不做；列表**禁用逐项入场** |
| Tab 切换用滑块位移指示器 | 与"即时高亮"冲突，且需跨页同步状态 | 0ms 颜色切换，无指示器 |
| Toast 与庆祝弹窗同时出现 | 视觉与读屏冲突 | 庆祝弹窗期间不弹 Toast，改用弹窗内文案 |
| 倒计时每秒做淡入淡出 | 一秒一闪，长时间引起视觉疲劳 | 仅替换字形，0ms |
| 滚动过程中修改状态 | 每帧 setState，掉帧 | 滚动停止后再处理，或用 `onScroll` 节流 ≥ 100ms |
| 常驻循环光晕/呼吸 | 持续占用合成线程，耗电 | 循环动画仅骨架屏，且只在加载中出现 |
| 多个 `animateTo` 嵌套 | 时长相乘，结束时机不可预测 | 单次 `animateTo` 内批量改状态 |
| 在 `aboutToAppear` 中立即 `animateTo` | 首帧未完成即动画，出现闪跳 | 延迟一帧（`setTimeout(…, 0)`）或放 `onAppear` |
| 用 `.animation()` 绑定高频变化属性 | 每次刷新重建动画对象 | 用 `animateTo` 显式控制 |

### 11.2 性能红线

| 指标 | 阈值 | 验证方式 |
| --- | --- | --- |
| 单帧耗时 | < 16.7ms（60fps） | DevEco Profiler 帧率视图 |
| 丢帧率 | < 1%（滚动与动画期间） | Profiler 长帧统计 |
| 同时进行的动画元素 | ≤ 12 | 代码评审 + Profiler |
| 冷启动到首屏可交互 | ≤ 1200ms | 启动耗时打点 |
| Tab 切换响应 | ≤ 100ms（视觉反馈） | 手动 + 打点 |
| 热力图节点数 | 单屏 ≤ 371 格；> 200 格时改 Canvas 绘制或 `.renderGroup(true)` 合并 | 组件树检查 |
| 动画期间 | 不发起网络请求、不解码图片、不做大对象拷贝 | 代码评审 |
