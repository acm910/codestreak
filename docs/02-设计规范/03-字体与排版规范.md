# 字体与排版规范

## 1. 目的与范围

本文定义 CodeStreak 的字族角色、中文字形落地裁决、字号阶梯、数字排版、截断与行宽规则、眉标（eyebrow）用法与文案长度上限。

- **负责**：字族、字号、行高、字重、字距、数字排版、截断、对齐、文案长度。
- **不负责**：颜色见[设计令牌规范](02-设计令牌规范.md)；间距与容器宽度见[布局栅格与间距规范](04-布局栅格与间距规范.md)；文案语气见[设计原则与视觉风格](01-设计原则与视觉风格.md) §7。
- **单位**：设计稿 1px = 1fp（按 360vp 宽、1rem=16px 换算），`fp` 数值与原型的 Tailwind `px` 数值 1:1 对应，不缩放。
- **基线**：原型 `docs/产品原型/**/code.html` 的排版类 + [原始设计说明](../产品原型/algorithmic_precision/DESIGN.md) 的 typography 段。

## 2. 三种字体角色

| 角色 | 字族 | 允许字重 | 承载内容 | 令牌前缀 |
| --- | --- | --- | --- | --- |
| 显示 / 数字 | Space Grotesk | 600 / 700 | 页面标题、卡片标题、连续天数、百分比、倒计时 | `headline-*` |
| 正文 | Geist | 400 / 500 | 说明段、正文、题目名、英文正文 | `body-*` |
| 元信息 | JetBrains Mono | 500 | 题目 ID、复杂度、时间、Rating、平台名、眉标、按钮文案 | `label-*` |

角色是**内容契约**而非装饰：同一类内容在任何页面必须使用同一角色——`CODESTREAK // CLI` 是 `label-sm` mono，`Today` 是 `headline-sm` Space Grotesk 600，`28 天连续打卡` 是 32fp 数字 + 14fp 系统中文单位，`历史最长: 64 天` 是 `label-sm` mono + `text.tertiary`；ID 出现在卡片右上角是 mono，出现在设置行里也必须是 mono。

## 3. 中文字形缺口与落地裁决

### 3.1 问题

Space Grotesk、Geist、JetBrains Mono **均无中文字形**（分别只覆盖拉丁/越南语扩展、拉丁、拉丁+西里尔）。直接指定 `fontFamily('Space Grotesk')` 渲染中文会逐字回落系统字体，造成中英混排行高不一致、基线错位、数字与单位间距不可控。

### 3.2 裁决（唯一方案）

| 内容类型 | 实际字族 | 令牌 | 说明 |
| --- | --- | --- | --- |
| 中文标题 / 中文正文 | **系统 HarmonyOS Sans** | `headline-*` / `body-*` | 代码中**不设置 `fontFamily`**，走系统默认中文字体；设计侧统一标注 "HarmonyOS Sans SC" |
| 阿拉伯数字、百分比、Rating | Space Grotesk | `headline-*` | 必须同时开启 tabular-nums（§5.1） |
| 英文标题 / 英文专名 | Space Grotesk | `headline-*` | 与数字同族，保持几何感 |
| 英文原名、比赛全名 | JetBrains Mono | `body-sm` | 与题目 ID 同列对齐（原型已用 `font-mono`） |
| 题目 ID、复杂度、时间、平台名 | JetBrains Mono | `label-md` / `label-sm` | — |
| 中英混排整句 | 系统 HarmonyOS Sans | `body-*` | **不拆 Span**：整句统一回落，避免基线错位与断行异常 |

- **中文标题字重**：HarmonyOS Sans 无 600 档，中文标题用 **700**；禁止对中文用 600（系统伪加粗，笔画糊）。西文标题保持 600。
- **视觉修正**：中文同 fp 下视觉尺寸大于拉丁，中文标题超过 8 个汉字时降一档（用 `headline-sm` 20fp 而非 `headline-lg` 28fp），避免标题占两行。

### 3.3 ArkUI 实现

```ts
// EntryAbility.ets —— 必须在 windowStage.loadContent 之前完成注册
import { font } from '@kit.ArkUI';

// commons/constants/DesignTokens.ets: DISPLAY='CsDisplay' / BODY='CsBody' / MONO='CsMono'
private registerFonts(): void {
  font.registerFont({ familyName: 'CsDisplay', familySrc: $rawfile('fonts/SpaceGrotesk-SemiBold.ttf'), weight: '600' });
  font.registerFont({ familyName: 'CsDisplay', familySrc: $rawfile('fonts/SpaceGrotesk-Bold.ttf'), weight: '700' });
  font.registerFont({ familyName: 'CsBody', familySrc: $rawfile('fonts/Geist-Regular.ttf'), weight: '400' });
  font.registerFont({ familyName: 'CsBody', familySrc: $rawfile('fonts/Geist-Medium.ttf'), weight: '500' });
  font.registerFont({ familyName: 'CsMono', familySrc: $rawfile('fonts/JetBrainsMono-Medium.ttf'), weight: '500' });
}
```

> `weight` 字段需 API 12+；基线不支持时按字重拆族名（`CsDisplay600` / `CsDisplay700`）。字体放 `resources/rawfile/fonts/`，三族五文件合计 ≤ 1.2MB。数字与中文单位必须拆 Span，否则单位会被西文字体接管：

```ts
Text() {
  Span('28').fontFamily(CsFont.DISPLAY).fontSize(32).fontWeight(FontWeight.Bold)
  Span(' ').fontSize(14)        // 半角空格 ≈ 3.6vp，即 space-xs
  Span('天连续打卡').fontSize(14)
}
.fontFeature('"tnum" 1')        // 等宽数字，作用于整个 Text
.lineHeight(40).maxLines(1)
```

### 3.4 降级链

| 令牌 | 首选 | 次选 | 兜底 | 降级后的表现与接受度 |
| --- | --- | --- | --- | --- |
| `CsDisplay` | SpaceGrotesk-*.ttf | — | 系统 700 | 几何感丢失，数字宽度仍靠 tnum 保证，**可接受** |
| `CsBody` | Geist-*.ttf | 系统 HarmonyOS Sans | 同上 | 中文场景本就回落，**可接受** |
| `CsMono` | JetBrainsMono-*.ttf | 系统 HarmonyOS Sans | 同上 | 拉丁等宽消失（`O`/`0`、`l`/`1` 难辨），ID 显示**不可接受**，构建必须拦住 |

CI 脚本断言 `resources/rawfile/fonts/` 下五个 ttf 存在且非 0 字节；运行期不弹提示，仅在"关于"页显示当前字族版本。

## 4. 字号全表

| 令牌 | 字号 | 行高 | 字重 | 字距 | 字族 | 主要用途 |
| --- | --- | --- | --- | --- | --- | --- |
| `headline-xl` | 40fp | 48fp | 700 | −1.2vp（−0.03em） | Space Grotesk | ≥600vp 断点的数字墙、年度回顾大数 |
| `headline-xl-mobile` | 32fp | 40fp | 700 | −0.64vp（−0.02em） | Space Grotesk | 手机 HUD 主数字：连续天数、补题率 `75%` |
| `headline-lg` | 28fp | 36fp | 600 | −0.56vp（−0.02em） | Space Grotesk | 页面级大标题、平板 Hero、统计大数（C-01 AppBar 标题不用本档） |
| `headline-sm` | 20fp | 28fp | 600 | −0.2vp（−0.01em） | Space Grotesk | C-01 AppBar 标题、卡片标题、区块标题（C-03）、弹窗标题、倒计时数字 |
| `body-lg` | 16fp | 24fp | 400 | 0 | Geist / 系统中文 | 说明段、空态描述、引导文案 |
| `body-md` | 14fp | 20fp | 400（题目名 500） | 0 | Geist / 系统中文 | 正文、题目名、列表主行 |
| `body-sm` | 12fp | 18fp | 400 | 0 | Geist / 系统中文 | 次级说明、英文原名、时间戳 |
| `label-lg` | 14fp | 20fp | 500 | +0.28vp（+0.02em） | JetBrains Mono | 大按钮文案、庆祝弹窗数值（`29 DAYS`） |
| `label-md` | 12fp | 16fp | 500 | +0.36vp（+0.03em） | JetBrains Mono | 标准按钮文案、标签文本、输入框 |
| `label-sm` | 10fp | 14fp | 500 | +0.5vp（+0.05em） | JetBrains Mono | 眉标 eyebrow、TabBar 标签、微元信息、图例 |

使用约束：

1. `headline-xl` 仅用于 ≥600vp（折叠屏展开/平板）；手机一律 `headline-xl-mobile`。
2. 同屏出现的字号档位 ≤ 3（§6）；新增字号必须落到本表，禁止 `fontSize(15)`、`fontSize(18)` 之类游离值。
3. `label-sm`（10fp）只允许拉丁文与数字，不承载中文正文；TabBar 中文标签为已知例外，按 §10 的 4 字上限使用。
4. HUD 大数字加 `.maxFontScale(1.3)`，防止超大字号把 32fp 撑爆卡片；正文类不加限制。
5. `headline-*` 与 `label-*` 的行高同时是**容器高度基准**（按钮高 = label-md 行高 16 + 上下各 12 = 40vp，见 04 §9）。

## 5. 数字排版规则

### 5.1 等宽数字（强制）

所有数字（天数、题数、百分比、Rating、倒计时、时间、排名）必须开启 tabular-nums，否则 1 与 8 的宽度差会让整行在刷新时左右抖动。

```ts
Text('1,284').fontFamily(CsFont.MONO).fontSize(12).fontFeature('"tnum" 1')
```

`fontFeature` 需 API 12+；不支持时降级为固定宽度容器（`.width(28)` + `TextAlign.End`）。数字禁止比例数字与斜体。

### 5.2 数字与单位的间距

| 组合 | 间距 | 示例 |
| --- | --- | --- |
| 数字 + 中文单位/量词 | 4vp（1 个单位同字号半角空格） | `28 天`、`42 分钟`、`15 题` |
| 数字 + 拉丁单位 | 4vp，单位用 `label-sm` / `body-sm` | `12ms`、`+25 EXP`、`18.4h` |
| 数字 + `%` | 0（不空格） | `75%`、`89%` |
| 分母 / 区间连接符 | 两侧各 2vp；区间用 `–`（en dash），不用 `-` | `15 / 20`、`1200–1400` |

### 5.3 千分位与精度

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 4 位及以上计数 | 必须千分位逗号 | `1,284 AC`、`14,290 名` |
| 年份 / 题号 | 不加逗号 | `2026`、`LC-206` |
| 百分比 | 整数不带小数；< 1% 写 `<1%` | `75%`、`<1%` |
| 时长 | < 1 小时用分钟；≥ 1 小时用 `18.4h`（1 位小数） | `42 分钟`、`18.4h` |
| Rating / 计时 | Rating 整数不千分位；计时整数 + 小写 `ms` | `2100`、`12ms` |

### 5.4 倒计时五位对齐

倒计时 HUD（C-26）按 **"数字 2 位 + 单位 3 字符 = 5 个字符位"** 的栅格对齐：四格等宽（`layoutWeight(1)`），任何一位进位都不改变格宽与整行宽度。

```text
┌───────────┬───────────┬───────────┬───────────┐
│    01     │    04     │    12     │    46     │  ← headline-sm 20/28 + tnum
│   DAY     │   HRS     │   MIN     │   SEC     │  ← label-sm 10/14，统一 3 字符
└───────────┴───────────┴───────────┴───────────┘
     79vp        79vp        79vp        79vp   ← (328 − 3×4) / 4
```

- 每格：底 `cs.color.surface.lowest`、圆角 4vp、内边距 4vp、格间距 4vp；数字前三格 `cs.color.primary.container`，秒格 `cs.color.secondary`。
- 单位标签统一 3 字符（`DAY/HRS/MIN/SEC`）：四格等宽时 4 字符标签不会撑破布局，但会挤压 20fp 数字的视觉重心，故按 3 字符归一；组件规范 C-26 现存 4 字符写法需同步。
- 数字 2 位补零，`09 → 10`、`59 → 00` 只替换字形；刷新用对齐秒边界的定时器（[交互与动效规范](06-交互与动效规范.md) §5 M-06），禁止淡入淡出。

## 6. 层级与嵌套限制

| 规则 | 规定 | 理由 |
| --- | --- | --- |
| 同屏字号档位 | ≤ 3 档 | 4 档以上失去主次，用户开始"读层级"而非"读内容" |
| 相邻层级差 | ≥ 4fp | `20 → 16` 视觉无差别，须 `20 → 14` |
| 卡片内文字层级 | ≤ 3 级：标题 / 正文 / 元信息 | 卡片是信息单元，不是页面 |
| 加粗表达层级 | 每张卡片最多 1 处加粗 | 两处加粗等于没有加粗 |
| 颜色表达层级 | 同字号最多 3 档（primary / secondary / tertiary） | 超出即失去语义 |
| `label-sm` 承载正文 / 标题嵌套 | 均禁止：10fp 中文不可读（对比度合规但尺寸不合规）；headline 中嵌 body 作从句时断行不可控 | — |

## 7. 截断与换行规则

| 元素 | 行数 | 溢出处理 | ArkUI 写法 | 备注 |
| --- | --- | --- | --- | --- |
| C-01 标题 | 1 | 省略号 | `.maxLines(1).textOverflow({ overflow: TextOverflow.Ellipsis })` | 设计期约束 ≤ 12 汉字 |
| 卡片标题（中文） | 1 | 省略号 | 同上 | 超过 12 汉字应改写，不放宽到 2 行 |
| 卡片副标题 / 英文原名 | 1 | 省略号 | 同上 | 与标题同一左基线 |
| 说明段 / 卡片正文 | 2 | 省略号 | `.maxLines(2)` | 第 3 行信息应移到详情页 |
| 按钮文案 | 1 | 不截断 | `.maxLines(1)` | 设计期约束 ≤ 5 汉字，超限即改文案 |
| 标签 Chip | 1 | 省略号 | `.maxLines(1)` + 最大宽 40% | 不换行、不撑破卡片 |
| 设置行副标题（C-36） | 2 | 省略号 | `.maxLines(2)` | 承载同步时间等动态内容 |
| 空态描述 / 弹窗正文 | 不截断 | 自然换行 | — | 设计期约束 ≤ 48 汉字；数字单元格永不换行 |

换行细则：中文按字断行（默认），英文按词断行（`.wordBreak(WordBreak.BREAK_WORD)`）；数字与单位用 `\u2060`（word joiner）连接，禁止被拆到两行；题目 ID 禁止换行与中间省略，宽度不足时整体降一档字号；禁止用固定 `.height()` 承载多行文本，一律用行高 × 行数的最小高度。

## 8. 行宽与对齐

| 项 | 规定 |
| --- | --- |
| 内容区宽度 | 360vp 稿上 328vp（左右各 16vp 外边距，见 04 §4） |
| 中文正文行宽 | ≤ 22 汉字 / 行（14fp 实际约 23 字，留 1 字余量） |
| 英文正文行宽 | ≤ 46 字符 / 行；段落最长 3 行 |
| 默认对齐 | 左对齐（`TextAlign.Start`），中英混排整句统一左对齐；禁止两端对齐与长段落居中 |
| 数字对齐 | 同列数字右对齐（`.textAlign(TextAlign.End)`），单位随数字右侧 |
| 标签对齐 | 左对齐；仅状态胶囊内容居中 |

## 9. 大写与小字距（eyebrow 眉标）规则

眉标是"这块数据是什么口径"的元信息，不是标题的装饰副本。

| 规则 | 规定 |
| --- | --- |
| 字符 | 只能拉丁大写字母、数字、空格、`/`、`//`、`·`；禁止中文与 emoji |
| 字号 / 字距 | `label-sm` 10fp / 行高 14 / 字重 500 / 字距 **+0.5vp（+0.05em）** |
| 颜色 | `cs.color.text.tertiary`；强调型眉标（如 `RATING: 900`）可用 `cs.color.tertiary` |
| 长度 | 2–24 字符；单词 ≤ 12 字符；超过改用中文 body-sm 并降为普通说明 |
| 分隔符 | 统一 `//`（品牌惯例 `CODESTREAK // CLI`），单段内不用 `-` |
| 位置 / 数量 | ① C-01 标题上方紧贴（间距 0）；② 区块标题右侧同基线。每区块 ≤ 1 个，同屏 ≤ 3 个 |
| 禁止 | 全大写中文、700 字重眉标、带背景块的眉标（如需背景用 C-12 Chip） |

## 10. 文案长度建议表

| 元素 | 上限 | 超限处理 | 示例 |
| --- | --- | --- | --- |
| 页面标题（C-01） | 12 汉字 / 20 字符 | 改写为短名 | 今日打卡、Problem Sets |
| 卡片标题 | 12 汉字 | 视为文案问题，不改行数 | 反转链表 |
| 卡片副标题 | 24 汉字 | 2 行截断 | 博弈论 / 数学 / CF Round 909 (Div. 3) |
| 区块标题（C-03） | 8 汉字 | 缩短 | 今日核心推荐 |
| 按钮 | 5 汉字 | 改图标 + 短词 | 完成打卡 |
| 标签 Chip | 6 汉字 | 每行最多 2 个 | 双指针 |
| 统计数值 | 5 字符位 | 超出改用单位（`1.2k`） | 28、384、75% |
| 空态标题 / 描述 | 10 / 40 汉字 | 描述拆两段 | 今天还没有推荐 |
| Toast（C-18） / 弹窗正文（C-16） | 18 / 48 汉字 | 超长改用抽屉 | 已同步至 4 个平台 / 记录已同步至云端矩阵 |
| TabBar 标签 | 4 汉字（固定） | 不缩短，改图标语义 | 今日打卡 / 题单矩阵 / 比赛日历 / 统计榜单 |

## 11. 实施与验证

业务代码统一用 `@Extend(Text)` 封装标题级样式（`fontSize/lineHeight/fontWeight/maxLines/textOverflow` 四件套），禁止直接写裸 `fontSize`。

- [ ] 全仓无游离字号（仅允许 §4 的 10 个令牌值）；中文标题字重 700，未出现伪加粗的 600。
- [ ] 三族字体在 EntryAbility 注册成功，首帧无字体闪烁（FOUT）。
- [ ] 所有数字开启 tabular-nums；倒计时刷新无水平抖动；眉标均拉丁大写、10fp、+0.5vp 字距、无中文。
- [ ] 截断元素均设 `maxLines` + `Ellipsis`，无固定高度裁切；文案长度逐条符合 §10。
