# 弹层与全局状态

本文定义 CodeStreak 的弹层层级、遮罩、开合与焦点规则，以及贯穿全 App 的 Toast、空态、错误、加载、离线、权限、同步与断签状态。组件视觉规格见 [组件规范](../02-设计规范/05-组件规范.md)（C-16/C-17/C-18/C-39/C-40），颜色令牌见 [设计令牌规范](../02-设计规范/02-设计令牌规范.md)，页面骨架与栅格见 [布局栅格与间距规范](../02-设计规范/04-布局栅格与间距规范.md)。

## 1. 层级模型与遮罩

### 1.1 五层层级

| 层 | 名称 | 载体 | z-index | 遮罩 | 说明 |
| --- | --- | --- | --- | --- | --- |
| L0 | 页面 | Navigation 内容区 | 0 | 无 | 可滚动内容，不含固定栏 |
| L1 | 固定栏 | C-01 AppBar / C-02 BottomTabBar | 100 | 无 | 常驻，弹层打开时被遮盖 |
| L2 | 底部抽屉 | C-17 BottomSheet | 1000 | `surface.dim`@80% + 8vp 模糊 | 满宽、上圆角 12vp |
| L3 | 全屏弹层 | C-16 CelebrationModal | 1200 | 同 L2 | 居中，四周留 16vp |
| L4 | 全局 Toast | C-18 | 1500 | 无 | 不阻塞点击，恒在最上 |
| L5 | 系统通知 | 系统通道 | — | — | 不可控，不参与应用内层级 |

递进关系：页面 < 底部抽屉 < 全屏弹层 < 全局 Toast < 系统通知。禁止跨层跳级，例如从页面直接弹全屏弹层（庆祝弹窗除外，它由打卡成功事件触发）。

### 1.2 遮罩规范

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 遮罩色 | `cs.color.surface.dim` @80% | 与画布同色相，靠不透明度压暗，不使用纯黑 |
| 背板模糊 | 8vp（`backdropBlur`） | 抽屉与弹层一致；禁止对已模糊层二次叠加 |
| 动效 | 淡入 180ms、淡出 150ms | Toast 与同步指示不受遮罩影响 |
| 点击行为 | 默认点击遮罩关闭，抓取/提交中除外 | 弹层内点击不穿透到页面 |
| 遮罩下内容 | 不可滚动、不可聚焦 | 用 `enabled(false)` 阻断手势，而非视觉遮挡 |
| 与 Toast 关系 | Toast 层级高于遮罩且不被模糊 | 弹层内的操作反馈优先用内联状态，不主动叠 Toast |

### 1.3 通用开合规则

| 场景 | 规则 |
| --- | --- |
| 进入动画 | 抽屉 240ms 上滑（cubic-bezier(0.2,0,0,1)）；全屏弹层 300ms `scale 0.95→1` + 淡入 |
| 退出动画 | 抽屉 180ms 下滑；弹层 150ms 缩小淡出 |
| 返回键 | 等价于"取消/关闭"；提交中与抓取中禁用 |
| 下滑关闭 | 仅抽屉支持，阈值 120vp 或速度 >800vp/s |
| 打开焦点 | 移入弹层首个可交互元素（输入类弹层为输入框） |
| 关闭焦点 | 回到触发源组件，滚动位置不重置 |
| 焦点陷阱 | 焦点循环在弹层内，遮罩不进入焦点序列 |
| 键盘处理 | 输入框获焦时抽屉整体上移，底部按钮随键盘上浮 16vp，始终高于键盘 |
| 防重复 | 同一弹层仅允许 1 个实例；重复触发只做前置聚焦，不叠层 |

### 4.2 空态（C-39）

| 页面 | 触发条件 | 标题 | 说明 | 主操作 | 图示建议 |
| --- | --- | --- | --- | --- | --- |
| P-01 | 今日无推荐（题单已刷完） | 今日暂无推荐 | 去题单矩阵挑一道新题，保持连胜 | 去题单矩阵 | 线性 `inbox` 32vp |
| P-02 | 搜索无结果 | 没有匹配的题目 | 试试 key: LC-15 或 tag:双指针 | 清空筛选 | 线性 `search_off` |
| P-02 | 未订阅任何题单 | 还没有订阅题单 | 从官方精选或外站导入开始 | 立即解析 | 线性 `playlist_add` |
| P-03 | 该平台近 30 天无赛事 | 暂无赛程 | 切换平台或查看全部赛事 | 查看全部 | 线性 `event_busy` |
| P-04 | 好友不足 3 人 | 好友榜数据不足 | 邀请队友一起打卡 | 分享邀请 | 线性 `group` |
| P-04 | 新用户热力图全 0 | 还没有提交记录 | 绑定平台后自动同步 | 去绑定 | 线性 `grid_off` |

规则：空态必须给主操作；统一 32vp 线性图标 + 64×64vp `surface.low` 容器，禁用插画；空态与骨架互斥，顺序为"先骨架、后空态"。

### 4.3 错误态

| 类型 | 触发 | 展示位置 | 文案 | 操作 |
| --- | --- | --- | --- | --- |
| 网络错误 | 无网或超时 ≥8s | 页面区块内 | 网络连接不可用 | 重试（保留滚动位置） |
| 服务错误 | HTTP 5xx | 页面区块内 | 服务暂时不可用，请稍后重试 | 重试 |
| 同步失败 | 平台授权失效 / 限流 | P-01 顶部条 + C-18 | Codeforces 同步失败：授权已失效 | 重新绑定 / 忽略 |
| 权限拒绝 | 通知或日历被拒 | O-09 抽屉（首版为系统弹窗 + C-18 说明） | 未获得通知权限，赛前提醒将无法送达 | 去系统设置 |
| 解析失败 | URL 抓取不到题单 | O-03 输入框下方 | 无法解析该题单，请确认链接公开可访问 | 重试 / 更换链接 |
| 数据异常 | 字段缺失 / 版本不兼容 | 页面区块内 | 数据格式异常，已为你刷新 | 刷新 |

规则：错误态必须提供重试入口；自动重试按 2s / 4s 退避，10s 内最多 2 次；文案不得暴露堆栈、HTTP 码或英文异常。

### 4.4 加载与骨架屏（C-40）

| 形态 | 用途 | 结构 | 时长策略 |
| --- | --- | --- | --- |
| 列表骨架 | P-02 题单矩阵库 | 3 行，每行高 92vp、圆角 12vp，含标签短块与标题长块 | >300ms 才显示，<300ms 直接出内容 |
| 热力图骨架 | P-04 提交活跃度矩阵 | 7 行 × 16 列，块 10×10vp、圆角 2vp、间距 2vp | 与真实矩阵同尺寸，避免布局跳动 |
| HUD 骨架 | P-03 赛事倒计时 | 眉标 1 条 + 标题 1 条 + 四格 52vp | 数据到达后 150ms 淡出 |
| 首次启动 | 冷启动 | 启动窗口取 `cs.color.surface`（#10141A），无骨架、无超过 800ms 的 Logo 动画 | 禁止整屏 loading 遮罩 |

规则：骨架不使用高光扫过或渐变（与"不靠阴影渐变表达层级"冲突），仅用不透明度 0.4→0.8 / 1200ms 呼吸。

### 4.5 离线态

| 项 | 规范 |
| --- | --- |
| 判定 | 系统网络不可用，或连续 3 次请求失败 |
| 展示 | AppBar 下方常驻 28vp 提示条（`surface.high` + 左 2vp `error`）："离线模式 · 展示最近同步数据"，右侧"重试"文字按钮 |
| 数据 | 只读缓存；打卡、导入等写操作禁用，并给 C-18"离线状态下不可打卡" |
| 恢复 | 网络恢复后静默重试，成功则提示条 3s 后淡出并给 C-18"已恢复在线，数据已更新" |
| 边界 | 离线不得清空列表；缓存超 24h 追加"数据可能不是最新" |

## 5. 状态互斥与优先级

同时发生时按下表顺序展示，数值越小越优先：

| 优先级 | 状态 | 抢占方式 | 被压制方 |
| --- | --- | --- | --- |
| P0 | 隐私 / 权限阻断（O-09 阻断型） | 独占全屏，不可关闭 | 全部 |
| P1 | 全屏弹层 O-01 | 独占焦点与遮罩 | 抽屉、Toast、页面内提示 |
| P2 | 底部抽屉 O-02 / O-03 | 独占焦点与遮罩 | 页面错误条、空态、骨架 |
| P3 | 页面级错误条（4.3 / 4.5） | 占据区块顶部 | 空态、骨架 |
| P4 | 空态 C-39 | 替换区块内容 | 骨架 |
| P5 | 骨架 C-40 | 替换区块内容 | — |
| P6 | 同步指示（4.7） | 叠加 AppBar，不占内容位 | — |
| P7 | Toast C-18 | 覆盖在最上层 | — |

| 同时发生 | 结论 |
| --- | --- |
| 弹层打开 + 触发 Toast | Toast 仍在弹层之上展示；弹层内的操作反馈改用内联状态，不主动弹 Toast |
| 骨架加载中 + 请求失败 | 立即结束骨架转错误态，不展示空态 |
| 空态 + 离线提示条 | 可共存：提示条在顶部，空态在区块内 |
| 断签提醒条 + 打卡成功弹窗 | 弹窗优先；关闭后提醒条因已打卡自动消失 |
| 抽屉打开 + 断签提醒到期 | 提醒延后到抽屉关闭后展示，不叠加 |
| 同步失败 + 打卡成功 Toast | 保留打卡成功 Toast；同步失败降级为 AppBar `error` 圆点 + 稍后 C-18 |
| 抓取中 + 用户返回 | 先走二次确认（O-08，首版为系统确认弹窗）；确认则中断，已解析结果写入草稿 |

## 6. 验收清单

- [ ] 层级 z-index 严格按第 1 节，Toast 恒高于遮罩且不阻塞点击。
- [ ] 遮罩统一 `surface.dim`@80% + 8vp 模糊，无纯黑遮罩或二次模糊。
- [ ] O-01 文案逐字一致：ACCEPTED! 连续达成 / 打卡成功，连胜延续！/ 连续天数 29 DAYS 🔥 / 获得积分 +25 EXP / 收到，继续冲刺。

- [ ] O-03 域名白名单生效，说明文案为"支持自动提取各题题目号，并统一映射为系统归一化难度"。
- [ ] 所有弹层支持返回键关闭（抓取中、提交中除外），并记录关闭来源埋点。
- [ ] 抽屉下滑阈值 120vp；键盘弹出时底部按钮始终高于键盘 16vp。
- [ ] Toast 同时最多 1 条、2.5s 消失、距 TabBar 12vp。
- [ ] 五个页面均定义空态、错误态、骨架态，空态主操作可执行。
- [ ] 错误态均有重试入口，10s 内自动重试不超过 2 次。
