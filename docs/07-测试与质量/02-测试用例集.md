# 测试用例集

## 1. 目的与范围

本文给出 v1.0 的**可执行用例基线**（111 条），覆盖四个一级页、启动与全局、同步与归一化、通知、安全、兼容性能、备份升级。用例是从 [页面设计](../03-页面设计/01-页面总览与原型映射.md) 的**状态矩阵**与 [平台同步与难度归一化](../04-技术设计/04-平台同步与难度归一化.md) 的**算法边界**推导出来的，不是臆造场景。

- 用例基线随需求冻结（W6）锁定；此后新增需求不进入本期用例集。
- 通过判据与门禁见 [通过条件与缺陷管理](03-通过条件与缺陷管理.md)；测试策略见 [测试方案总纲](01-测试方案总纲.md)。

## 2. 编号与字段规范

### 2.1 编号

```text
TC-<模块码>-<两位序号>

模块码：SYS 启动与全局 / TOD 今日打卡 / SET 题单矩阵 / CON 比赛日历 / STA 统计榜单
        SYN 同步与归一化 / NOT 通知提醒 / SEC 安全隐私 / COM 兼容性能 / BAK 备份升级
```

编号一经分配不复用；用例废弃标记 `[废弃]` 保留行，不删除编号。

### 2.2 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| ID | 是 | 见 2.1 |
| 场景 | 是 | 一句话说明"在什么条件下做什么" |
| 步骤与数据 | 是 | 关键操作与测试数据；多步用 `→` 连接 |
| 预期结果 | 是 | 可判定的事实；文案类必须与页面文档逐字一致 |
| P | 是 | P0 / P1 / P2（定义见 07-03 §5） |
| 自动化 | 是 | L1 单测 / L2 契约 / L4 UiTest / 手工 / 半自动 |

## 3. 设计方法

| 方法 | 应用场景 | 示例 |
| --- | --- | --- |
| 状态迁移 | 打卡、倒计时、同步任务 | 未打卡 → 部分 → 达标 → 归档 |
| 等价类 | 难度映射、筛选条件 | CF rating 五档取值 |
| 边界值 | 时间、计数、分页 | 23:59:59 打卡、第 500 条提交 |
| 判定表 | 权限 × 网络 × 登录态组合 | 拒绝通知 + 离线 + 未授权 |
| 正交组合 | 筛选（赛道 × 难度 × 平台 × 关键字） | 8 组高价值组合 |
| 错误推测 | 接口异常、脏数据 | 缺 rating、重复提交、超长标题 |

## 6. 用例评审与维护

1. **评审**：用例在 W2 完成首轮评审，参与人＝测试 + 开发 + 产品；评审通过率 100% 才可作为基线。

4. **执行记录**：每条用例记录"轮次/结果/缺陷 ID/执行人/日期"，随 07-03 §8 的报告归档。
