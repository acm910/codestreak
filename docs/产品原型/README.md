## 2. 如何使用

1. **看视觉**：先看 `screen.png`，它代表原型的最终渲染结果（含 AppBar、TabBar 与安全区布局）。
2. **看结构**：再读 `code.html`，其中 Tailwind 类名直接对应尺寸与颜色（`p-gutter`=16px、`rounded-xl`=12px、`space-md`=12px 等）。
3. **看交互**：页面底部 `<script>` 描述了原型已实现的交互（打卡、弹窗、筛选、抽屉、倒计时、Toast）。
4. **看口径**：任何与规范冲突之处，查 [原型差异与设计裁决](../06-附录/01-原型差异与设计裁决.md)。

技术说明：原型通过 CDN 引入 Tailwind 与 Google Fonts，**离线打开会丢失样式**；若需还原渲染效果，请在联网环境用浏览器打开，并按 390×844 或 360×800 的移动视口查看。

## 3. 已知问题（阅读时注意）

| 编号 | 问题 | 影响 |
| --- | --- | --- |
| P-01 | 四份 `code.html` 均有**超长单行**（HTML 头部与 Tailwind 配置挤在第 1–4 行内），逐行阅读工具会截断，易误判"缺 `<head>`/`<body>`/AppBar" | 四个页面结构完整；核对时以 `screen.png` 为准，必要时按字节读取整行 |
| P-02 | `codestreak_3` 中 ICPC、CCPC 两张卡片位于同一超长行内 | 实际共 6 张比赛卡，勿按 4 张设计 |
| P-03 | 四份原型的示例数据互不一致（历史最长 45 vs 64 天、击败 89% vs 89.4%、难度占比 33.8/3.2 与精确值 33.9/3.1） | 以"自洽数据集 v1"为准，见差异裁决第 6 节 |
| P-04 | 字体依赖 Google Fonts，离线或国内网络下会回退到系统字体 | 截图中中文并非设计字体，字体规范见 `02-03` |
| P-05 | 原型使用 Tailwind 任意值（如 `w-[270px]`、`text-[18px]`），未做 vp 换算；且 Tailwind 主题把圆角整体下调一档（卡片 8px、按钮 4px、胶囊 12px） | 落地按 1px ≈ 1vp 换算，圆角按规范阶梯取值（见 D-36） |
| P-06 | 部分按钮为 `<a href="#">`、部分交互仅有 Toast 占位 | 真实行为以页面设计文档为准 |

## 4. 目录维护规则

- 本目录**禁止修改**，包括修正错别字与样式；需要修正的内容一律写入 `docs/06-附录/01-原型差异与设计裁决.md`。
- 新增原型（如二级页）按 `codestreak_N` 递增命名，并在上表登记。
- 原型对应的规范映射见 [页面总览与原型映射](../03-页面设计/01-页面总览与原型映射.md)。
